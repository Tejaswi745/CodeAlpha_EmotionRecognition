# 🎙️ Emotion Recognition from Speech

This project focuses on detecting human emotions from speech audio using Machine Learning and Deep Learning techniques.

---

## 🚀 Features
- Extracts MFCC (Mel Frequency Cepstral Coefficients) from audio
- Trains a deep learning model for emotion classification
- Predicts emotions like happy, sad, angry, etc.

---

## 🛠️ Technologies Used
- Python
- TensorFlow / Keras
- Librosa
- NumPy
- Scikit-learn

---

## 📂 Dataset
- RAVDESS (Ryerson Audio-Visual Database of Emotional Speech and Song)
- Contains audio files from 24 actors with multiple emotions
